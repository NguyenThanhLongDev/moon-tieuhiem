📌 Trang này check cái gì?
Trong DB có 1 bản sao của tồn POS (lưu ở wh_variation_map.pos_remain_qty). Mỗi 2 giờ sync 1 lần từ POS API về DB.
→ Trang này so POS API (live) với bản sao DB. Nếu lệch = sync có bug, bản sao DB sai → bấm Resync để cập nhật.
⚠ KHÔNG phải so POS với Kho Vật Lý.
POS qty (shop khai báo) ≠ Kho VL qty (hàng thật trong kho) — lệch là bình thường. Để so 2 cái đó dùng Kiểm kho hoặc Báo cáo tồn kho.

💡 Quét mất 30-60s (gọi API tất cả shop active song song). Drift ≤ 50 đv thường là "live churn" (đang bán hàng giữa lúc sync chưa kịp).
