Thêm Facebook Access Token
Khuyến nghị: dùng System User Token (không hết hạn)
  1. Vào Business Manager → Cài đặt doanh nghiệp → System Users
  2. Tạo hoặc chọn System User (loại Admin)
  3. Bấm Tạo token mới → chọn App → tick quyền:
    business_management, pages_show_list, pages_read_engagement, ads_read, ads_management
  4. Copy token → paste vào ô bên dưới → Lưu
Hệ thống tự nhận diện và đánh dấu System User — không hết hạn
Phương án dự phòng: User token (~60 ngày)
Vào Graph API Explorer → chọn App → Generate User Token → cấp quyền business_management, ads_read, pages_show_list. Token sẽ tự động được đổi sang long-lived (~60 ngày).
Token sẽ được lưu vào DB và tự động đồng bộ BM, Pages, Tài khoản QC.
